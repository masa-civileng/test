# 小型輪荷重走行試験機 稼働計算

スマートフォンで使いやすい、静的HTML5の計算アプリです。サーバーやデータベースは不要で、計算はすべて端末内で行います。

## 主な機能

- 開始日時と走行回数から停止日時を計算
- 開始日時と停止日時から完了できる走行回数を逆算
- 1時間当たりの走行回数を変更可能（初期値 3,015回/時）
- 入力内容を端末に自動保存
- 結果のコピー
- スマートフォンのホーム画面への追加とオフライン利用（PWA）

## 計算条件

24時間連続稼働・途中停止なしを前提とします。停止日時からの逆算は、その時刻までに完了できる整数回数を切り捨てで表示します。

## GitHub Pagesで公開する手順

1. リポジトリの **Settings** を開く
2. 左側の **Pages** を開く
3. **Build and deployment** の Source を **GitHub Actions** に設定する
4. Actionsの `Deploy static site to GitHub Pages` が完了すると公開されます
